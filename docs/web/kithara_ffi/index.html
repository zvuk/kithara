Cross-platform FFI adapter for the kithara audio player.

Wraps kithara-play types behind an FFI-friendly API. Native targets (Apple / Android) use UniFFI to generate Swift / Kotlin bindings; wasm32 uses wasm-bindgen under web. src/lib.rs is the single structural boundary where target-conditional cfg gates live: shared FFI data types live in core, native-only bridges/runtime in native, and the wasm surface in web.
