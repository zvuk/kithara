KitharaPlayerItem

class KitharaPlayerItem

A single audio item that can be queued in KitharaPlayer.

All preferences (bitrate caps, ABR mode, headers) are frozen at construction. Loading starts automatically when the item is inserted into a KitharaPlayer.

val item = KitharaPlayerItem("https://example.com/audio.mp3")
player.insert(item)
player.play()
