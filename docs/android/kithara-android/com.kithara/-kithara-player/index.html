KitharaPlayer

class KitharaPlayer(config: KitharaPlayer.Config = Config())

Queue-based audio player.

Observe state for reactive updates, or read convenience accessors for the latest snapshot. Call Kithara.initialize before creating any instance.

val player = KitharaPlayer()
val item = KitharaPlayerItem("https://example.com/audio.mp3")
player.insert(item)
player.play()

A single DRM rule: a key processor bound to one or more domain patterns (exact "example.com", wildcard subdomain "*.example.com", or match-any "*"), plus optional headers / query params sent with matching key requests, and an optional per-rule salt forwarded to KeyProcessor.processKey.
