# A page with no line here is allowed nothing, so a new page has to be priced
# before the gate passes. These numbers are a debt, not a target: every control
# that lands must lower the pages it appears on, and no number may rise without
# a reason written next to it.
#
# Measured 2026-08-09 at 1100x720 scale 1, iced through wgpu against masonry
# through Vello, both clearing to the skin's page colour. The floor is under 1%:
# the two engines disagree on antialiased edges and on text gamma.

# be reachable at all. Every share fell by a few tenths against the same

# numbers below were left where they were rather than tightened onto a window
# size, since none of them was earned by a page drawing better.

# Motion landed 2026-08-16 at 1.0% of pixels and 1.1% of ink, which is the
# floor every ordinary page sits on. Turning and scaling a control was expected
# to cost more, because it puts ink on edges that are no longer axis-aligned and
# the two rasterisers round those differently; it did not, because the pose is
# resolved in the neutral list and both hosts flatten the same placed geometry.
#
# The stage row landed the same day and reads 1.2% of both, the rise being ink
# it added rather than disagreement about it. Read that number with the picture
# beside it: this page's first stage measured 1.4% while the retained host
# stretched a 120-wide chip across the whole row and the immediate host clipped
# it to 107 — two plainly different pictures, both inside this budget. The band
# is identical now because both hosts resolve the box the same way, not because
# the share went down.
#
# That page is 21-objects.png as of 2026-08-16, having been 21-motion.png until

# forced the split: the column ran past 720 logical pixels, the immediate host

# measured 1.4% — the third time in this campaign that the share stayed inside
# budget while the two pictures plainly differed.

# Sprites, 2026-08-16, at 1.8% of pixels and 1.5% of ink. Eight frames of one
# sheet held at their own second, one sheet played off the host's own clock and
# one scrubbed by the fader beside it, and two more carried by moving objects.
#
# Its first capture read 1.9% and hid a plainly different picture, the fourth
# time in this campaign a share inside a neighbouring page's budget did: the
# turned sprite's ink sat at x 282..301 here against 290..310 there, an exact
